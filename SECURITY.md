# Security and data handling

Please do not report ordinary research questions as security vulnerabilities. For a vulnerability involving credentials, container execution, dependency integrity, or unintended data exposure, use GitHub's private **Report a vulnerability** form for this repository. If that form is unavailable, contact [@seanyepez](https://github.com/seanyepez) through GitHub before sharing sensitive details; do not put them in a public issue.

Never attach RiceChem rows, model weights, raw predictions, credentials, private infrastructure identifiers, or student information to an issue or pull request. Reproduce problems with synthetic fixtures whenever possible.
